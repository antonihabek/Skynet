# Code of conduct

Skynet OS follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique the work and not the person, and keep
technical disagreement technical. Harassment, personal attacks and discriminatory language are not
tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Report conduct concerns privately to the maintainer, [@antonihabek](https://github.com/antonihabek):
open this repository's **Security** tab → **Report a vulnerability** (only the maintainers can see
what is sent there) and start the title with "Conduct". Reports are handled confidentially, and the
Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
decide what happens next.
